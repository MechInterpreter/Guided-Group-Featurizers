STAGE3, deterministic locks and scoring (same commands on Colab or a local unpacked source package):
python run_evaluation.py --root <evaluation_root> --phase lock-presence
python run_evaluation.py --root <evaluation_root> --phase target-calibration

The first command validates all received presence files, freezes separate calibration/audit label locks and validates the required fixed QA second pass. The second uses calibration presence ONLY to freeze q95/q90 thresholds, full native rankings and1/2/4/8 selections for EVERY category and method. q95/budget1 defines the common target-alignment link; no reconstruction proxy or intended category-slot selector. It generates method-blinded calibration target-alignment cards.

Coherence batch templates are under reviews/coherence/batches/context1,context2,context3. Completed disjoint batches go under batch_labels/<context>. Use prepare_evaluation_reviews.py --root <root> --phase assemble-context1 (and likewise2/3) to validate coverage and retain every raw source before the final scorer joins method identities. A full context template can also be completed directly.

Fill reviews/alignment_calibration/labels.json from its template, then:
python run_evaluation.py --root <evaluation_root> --phase target-audit

This locks calibration alignment before generating corresponding audit alignment cards. Fill reviews/alignment_audit/labels.json and the three coherence context label files, then:
python run_evaluation.py --root <evaluation_root> --phase score

Scoring verifies frozen mappings, card hashes, source labels and selectors. It computes original signed-top4 OR coverage/FPR/precision, positive/negative-support Jaccard, incremental/unique coverage and all support counts. Low-support categories keep null metrics and status. Majority AI pair coherence retains all native groups/pairs and unresolved bounds. Target alignment retains all six planned views and codes target/context/other/mixed/unclear/missing.
